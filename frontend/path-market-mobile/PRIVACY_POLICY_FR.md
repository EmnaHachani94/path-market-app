# Politique de Confidentialité et RGPD - PathMarket

## 1. Introduction

PathMarket respecte votre vie privée et s'engage à protéger vos données personnelles conformément au Règlement Général sur la Protection des Données (RGPD).

Cette politique explique comment nous collectons, utilisons et protégeons vos données lorsque vous utilisez notre application mobile.

---

## 2. Données Collectées

### 2.1 Données Essentielles

- **Identité** : Nom, email, numéro de téléphone (pour l'authentification et la communication)
- **Compte utilisateur** : Identifiant unique, mot de passe chiffré
- **Listes de courses** : Les articles et listes que vous créez
- **Localisation approximative** : Pour adapter le service à votre région
- **Logs de connexion** : Adresse IP, date/heure d'accès (pour la sécurité)

### 2.2 Données Analytiques (optionnel)

- **Utilisation de l'app** : Quels écrans vous visitez, combien de temps vous restez
- **Actions** : Création de listes, recherches, partages
- **Informations sur l'appareil** : Modèle, système d'exploitation, version de l'app

### 2.3 Données Marketing (optionnel)

- **Préférences** : Articles et catégories qui vous intéressent
- **Email pour les offres** : Actualités, promotions, nouvelles fonctionnalités

---

## 3. Base Légale du Traitement

Nous ne traitons vos données que sur les bases suivantes :

- **Contrat** : Nécessaire pour fournir le service
- **Consentement** : Pour les données analytiques et marketing
- **Obligation légale** : Si la loi l'exige (ex. : fraude)
- **Intérêt légitime** : Sécurité et amélioration de l'app

---

## 4. Vos Droits RGPD

Vous avez le droit de :

✓ **Droit d'accès** : Demander une copie de vos données  
✓ **Droit de rectification** : Corriger vos informations  
✓ **Droit à l'effacement** ("Droit à l'oubli") : Supprimer vos données  
✓ **Droit à la portabilité** : Exporter vos données dans un format courant  
✓ **Droit à la limitation** : Limiter le traitement de vos données  
✓ **Droit d'opposition** : Vous opposer à certains traitements  
✓ **Droit de retirer votre consentement** : À tout moment et sans justification

### Pour exercer vos droits :

- Contactez-nous via l'app (menu Paramètres → Vie Privée → Demander l'accès)
- Ou envoyez un email à : **privacy@pathmarket.com**

---

## 5. Conservation des Données

| Type de données     | Durée de conservation              |
| ------------------- | ---------------------------------- |
| Compte actif        | Pendant la durée de votre compte   |
| Listes de courses   | Pendant la durée de votre compte   |
| Logs de sécurité    | 90 jours                           |
| Données analytiques | 12 mois (anonymisées après 6 mois) |
| Données marketing   | Jusqu'à révocation du consentement |

---

## 6. Sécurité des Données

Nous mettons en place :

- **Chiffrement en transit** : HTTPS/TLS pour toutes les communications
- **Chiffrement au repos** : Chiffrement des données sensibles en base de données
- **Contrôle d'accès** : Accès restreint aux données sensibles
- **Authentification sécurisée** : Tokens JWT, mots de passe hashés (bcrypt)
- **Audits de sécurité** : Tests réguliers de pénétration
- **Notification de fuite** : En cas de violation, notification sous 72h à la CNIL et aux utilisateurs

---

## 7. Partage de Données

Nous **ne vendons jamais** vos données. Nous pouvons les partager uniquement avec :

- **Sous-traitants** : Hébergement (AWS), services de paiement, support client
- **Partenaires technologiques** : Google Analytics (optionnel selon votre consentement)
- **Obligations légales** : Si la loi l'exige

Tous les sous-traitants signent des contrats de traitement des données (DPA).

## 9. Transferts Internationaux

Vos données peuvent être transférées et traitées en dehors de l'UE (ex : États-Unis). Nous assurons que ces transferts respectent le RGPD via :

- **Clauses contractuelles types** (SCCs)
- **Adéquation de la Commission Européenne**

---

## 10. Durée de Rétention et Suppression

Vous pouvez demander la suppression complète de votre compte à tout moment.  
Cela entraînera :

- Suppression immédiate de votre profil
- Suppression de vos listes de courses
- Suppression des données personnelles

Les logs de sécurité seront conservés 90 jours pour les enquêtes de fraude.
